## 💡 專案理念 (Concept)

市面上的 AI PPT 工具（如 Gamma、Copilot 等）往往需要消耗大量 Token 或付費點數。**稿定 P.P.Done** 採取「架構與邏輯先行」策略：
1. **慳 Token 省成本**：先為你打磨好高質量的「簡報大綱」與「演講備註 (Speaker Notes)」。
2. **專屬 Prompt 一鍵複製**：針對你的目標 AI 工具（Gamma, ChatGPT VBA, Copilot, Marp 等），自動生成結構化提示詞，貼上即可生成高品質簡報。

---

## ✨ 核心特色 (Key Features)

- 💼 **管顧級與 ISO 治理邏輯 (Consultant & ISO Frameworks)**：
  - 內建 PDCA 循環、ISO 42001 AI 治理、ISO 31000 風險評估、董事會 Executive Summary 及專業調解溝通等多種專業框架。
- 🎯 **跨平台 AI 工具 Prompt 優化 (Tailored AI Prompts)**：
  - 支援 **Gamma App** (Card-by-Card 邏輯 + Image Prompt)
  - 支援 **ChatGPT / Claude** (可直接執行的 PowerPoint VBA Code / Marp Markdown)
  - 支援 **Microsoft Copilot**、**Tome**、**Canva AI** 等平台。
- ⏱️ **時間與節奏自動推算 (Smart Pace Calculation)**：
  - 輸入預計演講分鐘數與節奏（慢/中/快），自動推算最佳投影片張數。
- 🗣️ **預備講稿備註 (Speaker Notes)**：
  - 遵循「Don't Read Slides」原則，每頁提供 2-3 句講者口述備註。
- 🔒 **雙軌金鑰與資安防護 (Dual API Key & Privacy)**：
  - 提供公共免費體驗額度，同時支援使用者自備金鑰（Session 級別留存，保障企業機密數據）。
- 🌐 **全中英雙語 UI (Full Bilingual UI)**：
  - 一鍵切換繁體中文或 Full English 介面與輸出內容。
